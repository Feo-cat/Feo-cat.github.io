Nginx 入门笔记

发表于2026-05-17|更新于2026-09-01|后端与基础设施
|阅读时长:6分钟

Nginx 是一款高性能的 Web 服务器，也常被用作反向代理、负载均衡和静态资源服务器。它占用资源少、并发能力强，是后端部署中非常常见的基础组件。

本文聚焦通过 Linux 发行版包管理器安装的 Nginx。命令按官方文档校对，但没有绑定某一台实际服务器作为测试环境。systemctl 相关命令只适用于使用 systemd、并且安装包已经提供 nginx.service 的环境；容器部署和源码安装不在这一前提内。

Nginx 是什么

Nginx 是一个开源的 HTTP 服务器软件。和传统 Web 服务器相比，Nginx 更擅长处理高并发请求，因此经常用于网站入口层。

常见用途包括：

  • 部署静态网站
  • 反向代理后端服务
  • 配置 HTTPS
  • 做负载均衡
  • 缓存静态资源
  • 控制访问权限

不同发行版、软件仓库和安装方式可能使用不同的配置目录。动手修改前，先确认当前系统和 Nginx 的编译参数：

常见配置文件位置

通过发行版包安装时，主配置文件通常位于 /etc/nginx/nginx.conf，但站点配置的组织方式并不统一。

Ubuntu / Debian 发行版包

  • 主配置：/etc/nginx/nginx.conf
  • 站点配置：写入 /etc/nginx/sites-available/，启用后链接到 sites-enabled/
  • 默认静态目录：常见为 /var/www/html
  • 日志目录：通常为 /var/log/nginx/

RHEL 9 发行版包

  • 主配置：/etc/nginx/nginx.conf
  • 站点配置：写入 nginx.conf 的 http 块，或放入其实际包含的 conf.d/*.conf
  • 默认静态目录：/usr/share/nginx/html
  • 日志目录：通常为 /var/log/nginx/

sites-available 和 sites-enabled 是 Ubuntu/Debian 发行版包的常见组织方式，不是 Nginx 本身强制规定的目录。即使系统属于 Debian 系，改用 nginx.org 官方包后也不应假设它们一定存在。

小结

Nginx 是后端部署中非常重要的工具。它不仅可以作为 Web 服务器，还可以承担反向代理、负载均衡、HTTPS 配置等职责。

对于初学者来说，可以先掌握以下几个重点：

  • server 用来定义一个站点
  • location 用来匹配请求路径
  • root 用来指定静态资源目录
  • proxy_pass 用来转发请求
  • 修改配置后先执行 sudo nginx -t
  • 配置无误后再按当前运行方式重新加载
  • 先通过 nginx -V 和 nginx -T 确认真实路径，不照搬其他系统的目录
  • systemctl 只适用于存在 systemd 服务单元的安装方式

掌握这些基础内容后，就可以完成大多数简单的网站部署和后端代理配置。
